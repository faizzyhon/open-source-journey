# Contributing

Thanks for stopping by! This is a personal log repo, but suggestions and corrections are welcome.

## Ways to contribute

- **Found a typo or broken link?** Open an issue or send a PR.
- **Know a great open source project I should contribute to next?** File an issue with the `suggestion` label.
- **Spotted a stale entry in the roadmap?** Open a PR to update it.

## How to send a PR

1. Fork the repo.
2. Create a branch: `git checkout -b your-change-name`
3. Make your change and commit with a clear message.
4. Push and open a PR against `main`.

## Code of conduct

Be respectful. Be constructive. That's it.
